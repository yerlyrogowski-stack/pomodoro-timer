## Project overview

A single-file desktop Pomodoro timer (`pomodoro.html`) that runs in any browser — no dependencies, no build step, no server required.

## How to run / test

Open `pomodoro.html` directly in a browser:
```powershell
Start-Process pomodoro.html
```

That's it. No build, no lint, no tests.
